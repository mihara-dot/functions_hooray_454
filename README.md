# 

# \## Задача

# 

# Даны два массива вещественных чисел W и D, а также пороговое значение r. Необходимо найти сумму элементов каждого массива, которые больше r.

# 

# Для вычисления используется одна общая функция, которая вызывается отдельно для каждого массива.

# 

# \## Ввод данных

# 

# Данные вводятся с клавиатуры в следующем порядке:

# 

# 1\. Пороговое значение r.

# 2\. Количество элементов массива W.

# 3\. Количество элементов массива D.

# 4\. Элементы массива W.

# 5\. Элементы массива D.

# 

# Ограничения:

# \- Размер каждого массива — от 1 до 100 элементов.

# \- Модуль каждого элемента — не больше 1000.

# 

# \## Запуск

# 

# 1\. Открыть проект в Visual Studio.

# 2\. Собрать программу.

# 3\. Запустить программу.

# 4\. Ввести пороговое значение, размеры массивов и их элементы.

# 5\. Получить суммы подходящих элементов обоих массивов.

# 

# При некорректном вводе программа выводит `INVALID`.
